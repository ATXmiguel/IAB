IAB — Instituto de Astronomia Brasileiro

O que é o IAB?

O IAB é um projeto social/escolar criado em 2025 com o intuito de ampliar os conhecimentos gerais dos integrantes

O que o projeto tem até agora
-Portugol
Um programa com mais de 2.500 linhas de código feito em Portugol
O usuário navega por menus e acessa conteúdos sobre astronomia
Desenvolvido do zero pela equipe do projeto
Usado em palestras escolares.
-PowerPoint
90 slides no PowerPoint com conteúdo visual sobre o espaço
Usado em palestras escolares.
-Word
90 páginas no Word criados para a expansão do conhecimento e para a comunidade ter a oportunidade de novos ares!
Usado em palestras escolares.

Próximos passos

-Desenvolver o projeto e expandi-lo.
